## Главное новое
1. **Проверка коэффициента \(\pi\) для радиуса Bose star.** Уравнения (g), (crosssec_via_g), (Rc) исходного TeX дают радиус в \(\pi\) раз больше позднего уравнения (RbsSIDM). Важно проверить: обозначает ли второе характерную длину вместо радиуса первого нуля плотности. [01](01-bosestar-radius-pi-audit.md).
2. **Волновой режим нельзя переносить с fuzzy DM на 86 эВ без анализа заполнений.** При исходных масштабах F583-4 \(\lambda_{\rm th}\approx39.1\) мкм, \(n\lambda_{\rm th}^3\simeq2.64\) (с округленным m=86 эВ); большая фазовая заполненность характерна лишь для низкого импульса, а не автоматически для всей массы. [02](02-phase-space-and-relaxation.md).
3. **Начальная теплая доля != неконденсированная доля позднего гало.** Выведен контролируемый предельный закон роста холодных возмущений в присутствии компоненты, однородной на данном масштабе. [03](03-mixed-primordial-growth.md).
4. **Космологический путь восстановления гипотезы.** Рассмотрено стимулированное рождение низкоимпульсных бозонов из работ Yin (2023), Sakurai & Yin (2025); кинетическая связь с наблюдаемым гало остается нерешенной. [04](04-model-bridges-and-falsifiers.md).
5. **Новый профиль конечной массы:** изучена возможная связь с теоремами устойчивости из кинетической теории King/Vlasov и пределы применимости. [05](05-stability-and-thermodynamics.md).
6. **Сопоставление литературы:** целенаправленный список тематически критичных научных первоисточников, включая свежие 2025–2026 работы с явной глубиной проверки, классификацией по силе связи и аргументами за/против. [Обзор](literature/critical-theory-crosswalk.md).
7. **План статей и критерии отказа:** приоритеты исходя из физической содержательности, а не числа черновиков. [План](06-publication-branches.md).

## Обязательные ограничения
- Числа по 86 эВ — условные, на параметрах одной галактики и фиксированных физических допущениях. Физически «прогнозируемая масса» с учетом округлений и выбора профиля не определена.
- Вся литература просматривается как минимум по аннотациям/описаниям; *не* утверждается постраничное чтение всего текста всех цитируемых публикаций.
- Классическая/гравитационная коллизионная релаксация, wave kinetic/квазичастицы и коллективная violent relaxation — **разные механизмы**.
- Свободный пробег, баллистическое расстояние, Jeans scale и реликтовый transfer half-mode — **разные измеряемые величины**.
- Статическая Vlasov-положительность и столкновительная термодинамическая устойчивость — **разные утверждения**.
- Малость Bose-star радиуса не доказывает существование большой космологической популяции этих объектов.
