# Первый связанный Collision + Liouville FRW split-step: короткое структурное испытание

**21.11.2026.** После [физического FRW no-go неподвижных резонансных троек](FRW-RESONANCE-DRIFT.md), [комовингового number-preserving remap](PARENT-Q-REMAP.md) и [проверки достижимости энергии при Pauli](PAULI-ENERGY-BOUNDS.md) реализован первый **совместный** численный шаг трёхкомпонентных столкновений и редшифта.

Новый модуль [narrow_closed_frw_split.py](narrow_closed_frw_split.py) проводит короткую последовательность в радиационном фоновом расширении с постоянным g*S, \(x=M_1/T=0.0200\to0.0202\) и условным \(\kappa=\Gamma/H(M_1)=500\). Для заданного радиационного \(H(x)=H(M_1)/x^2\) используется \(d(t\Gamma)/dx=\kappa x\). Это структурный тест, **не физическая калибровка микрофизики**.

На каждом шаге:

1. ПОЛНОСТЬЮ пересоздаётся текущий on-shell collision graph с \(M_1/T=x\), отдельным набором порогово допустимых пар и точными дискретными энергиям матери \(E_{1,k}=e_{\phi,i}+e_{\chi_2,j}\). Число независимых collision invariants обязано равняться трём. Как только множество общих parent energy centers перестаёт совпадать либо один Eцентр становится меньше текущей массы, программа **отказывается продолжать**, вместо скрытого удаления физической популяции.
2. Замкнутый χ1↔χ2+φ BDF с аналитическим sparse Jacobian обновляет все три occupations. На этом collision substep дискретная энергия и два независимых числовых заряда сохраняются.
3. В отсутствие столкновений при FRW-части дочерние безмассовые распределения остаются в q=p/T. Материнские occupation переносятся по настоящему комовинговому q с q³ весами между ДВУМЯ мгновенными энергетическими сетками, сохраняя материнское число и Pauli bound.
4. Чётко разделены: (a) невязка энергии принятой дискретной collision-системы; (b) расхождение между **физическим** энергетическим интегралом матери по q и его сеточным значением на collision substep; (c) физическая свободная смена \(\rho/T^4\) при редшифте (работа давления); (d) собственная численная энергоошибка ремаппинга при **одном и том же** конечном x.

Чтобы сравнивать число в разных x, глобальная область комовинговых импульсов матери фиксирована. Размер последней ячейки одинаков по q для каждого шага, в отличие от исходной плоской resonance grid, у которой верхняя граница физических импульсов немного сдвигалась при изменении x.

**Существенные ограничения:** эта модель принципиально ограничена узким диапазоном, в котором состав уникальных материнских energy modes не изменяется, хотя отдельные on-shell пары уже исключаются при росте x. Начальная материнская thermal популяция обрезана на небольшом UV cutoff, предположена внешне заданная RD Hubble-функция и постоянное g*S. ПОДЧЁРКНУТО: сохранение дискретной энергии в столкновительном шаге не тождественно сохранению полной физической энергии при FRW; численная ошибка energy-remap остаётся ненулевой и измеряется. Это не готовая полноценная closed FRW кинетика.

Контрольный тест проверяет пересоздание пороговых каналов, сохранение обоих комовинговых зарядов после всей цепочки шагов, дискретный collision energy balance, Pauli, явные отдельные физические/численные energy-компоненты и приблизительную согласованность при удвоении числа x-шагов.

Воспроизведение: python kinetics/narrow_closed_frw_split.py; python -m pytest -q tests/test_narrow_closed_frw_split.py.

**Остающийся фундаментальный барьер:** перестроение parent energy modes при пересечении порога без потери χ1 и одновременное сохранение полной физической FRW энергии/работы, H-теоремы и единой глобальной occupancy. Требуется независимая сеточная сходимость и значительно более длинный x-интервал, прежде чем можно получить freeze-out f(q) для CLASS.
