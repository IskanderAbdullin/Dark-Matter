# Квантовая энтропия при перестройке Bose/Fermi-сеток: строгая проверка эффекта огрубления

**21.11.2026.** После [консервативного переноса всех трёх популяций](DAUGHTER-UV-REGRID.md) доказано независимое математическое свойство: **положительный перекрывающий finite-volume q³-remap не уменьшает дискретную квантовую энтропию** каждого вида, если добавленные UV-ячейки считаются пустыми.

Для бозона при f≥0 \(s_B(f)=(1+f)\ln(1+f)-f\ln f\). Для фермиона при 0≤f≤1 \(s_F(f)=-f\ln f-(1-f)\ln(1-f)\). Оба функционала **вогнутые**. Если внутри старых ячеек occupation постоянная, а в новых UV-областях полагается f=0, новая occupation в каждом бине есть выпуклая комбинация исходных значений по фазовому объёму \(q²dq\). По неравенству Йенсена:

\[
S(f_{\rm new})\ge S(f_{\rm old})
\]

в конечнобиновом coarse-graining представлении. Это справедливо даже при \(f_{\phi}\gg1\), где Pauli-предел для бозонов применять запрещено. Реализация [quantum_regrid_entropy.py](quantum_regrid_entropy.py) использует численно устойчивую функцию xlogy для пределов f=0,1.

Проверяются индивидуальные энтропии χ1, χ2, φ и их сумма при x=.020→.030 и одновременно Rmax=300→500, а также **два независимых комовинговых заряда** и отдельная энергоошибка проекции. Принципиальная оговорка: энтропия **увеличивается численно из-за усреднения**. Нельзя объявлять это реальной физической H-теоремой для динамической полной FRW, где между столкновениями истинная Liouville-эволюция сохраняет тонкозернистую энтропию. Следовательно, даже монотонный рост численной энтропии вместе с обоими числами **не удостоверяет физическую форму холодной тёмной материи**.

Этот тест не решает проблему физического energy mismatch, расширения неизвестного UV-хвоста, микрофизической тепловой связи, динамической нулевой моды и наблюдательного CLASS likelihood. Но предоставляет обязательный контроль того, что алгоритм с высокими Bose occupations не создал отрицательных/Pauli-невозможных состояний и что его энтропийный эффект правильно маркируется как численное огрубление.

Воспроизведение: python kinetics/quantum_regrid_entropy.py; python -m pytest -q tests/test_quantum_regrid_entropy.py.
