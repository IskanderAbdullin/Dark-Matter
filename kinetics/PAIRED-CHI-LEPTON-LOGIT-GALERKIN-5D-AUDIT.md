# Восстановление квантовой H-теоремы в χ–ℓ 2→2 event projection: Fermi-logit Galerkin (2026-11-22)

## Исходный отрицательный научный результат и гипотеза

Предыдущий [строгий контрпример](PAIRED-CHI-LEPTON-BARYCENTRIC-5D-AUDIT.md) показал, что энергоконсервативная χ–ℓ 2→2 event-deposition на χ и лептонные energy-bins может предсказывать **отрицательную** дискретную энтропию при исходном истинном `Sdot_event>0`. Причина — рассогласование двух операций: Pauli F/R оценивается по непрерывной произвольной f(E), а производная бин-энтропии по logit[f(E_i)] в дискретных узлах. Вопрос: можно ли исправить именно **структурную** причину и строго вернуть H-теорему без искусственного clipping, не скрывая сильную спектральную ошибку грубой сетки?

Предварительный критерий: использовать **одни и те же** неотрицательные barycentric энергии `α_i(E)` и для deposition, и для интерполяции **фермионных log-odds** `ℓ(E)=log[f(E)/(1−f(E))]`. Тогда для каждого события дискретное `Sdot_bins` должно алгебраически совпадать с `Jln(F/R)≥0`; при этом число/энергия должны остаться неизменными. Независимый внешний эталон — старый исходный аналитически вычисляемый `fχ(E),fℓ(ω)` на *той же 5D Pauli quadrature*, который разоблачает ошибки формы. Отдельно проверить FD limit с affine log-odds.

## Структурно-сохраняющая формула и доказательство

Для узлов энергии `E_i` с физическими `0<f_i<1` определим **на каждой элементарной χ+ℓ 2→2 реакции**

```
ℓχ(E) = Σ_i α_i(E) logit(fχ,i)
ℓℓ(ω) = Σ_j β_j(ω) logit(fℓ,j)
fχ,event(E) = expit(ℓχ(E))
fℓ,event(ω) = expit(ℓℓ(ω)).
```

Коэффициенты `α,β≥0`, `Σα=Σβ=1`, `Σ E_i α_i(E)=E`, `Σ ω_j β_j(ω)=ω` точно воспроизводят нулевой и первый моменты. После физического on-shell `χ(E)+ℓ(ω)↔χ(E′)+ℓ(ω′)` и finite-mV matrix element одна и та же F/R микрособытийная разность `J` переносит количество с начальных χ/ℓ энергий на конечные **теми же** α,β.

Тогда:

```
Sdot_bins = -Σ_i dNχ_i logit(fχ,i)
            -Σ_j dNℓ_j logit(fℓ,j)
          = Σ_events W J [
                ℓχ(E)+ℓℓ(ω)-ℓχ(E′)-ℓℓ(ω′)]
          = Σ_events W (F-R) log(F/R) >= 0 .
```

Последнее равенство следует непосредственно из `F=fχ(E)fℓ(ω)(1−fχ(E′))(1−fℓ(ω′))`, `R=fχ(E′)fℓ(ω′)(1−fχ(E))(1−fℓ(ω))`, потому что logit[(event f)] возвращает именно реконструированный `ℓ`. Это **локальное неравенство** для каждого события и всех внутренних fermion f∈(0,1), а не приближённая численная коррекция S после её расчёта.

Тот же paired source сохраняет `Nχ,Nℓ` и `Qχ+Qℓ=0` по первой моментной формуле. Для FD распределений при общих/различных `Tχ,Tℓ` их logit affine по энергии, поэтому reconstruction в точности возвращает соответствующую FD — отделённый аналитический контроль. Структура — дискретный **entropy-compatible instantaneous Pauli source**, но **не** ещё time-stepper с сохранением 0≤f_i≤1 после конечного dt; не называть его завершённым нелинейным physical strong collision solver.

## Сеточный эксперимент и оставшаяся отрицательная систематика

Физический scope без изменений: условный vectorlike χ–ℓ `Mχ=.1,mℓ=0,G=.001,mV=.1`, `Treference=1`, единицы условные, Gauss incoming p,k,μ `4×4×4`, outgoing `12×12`, incoming kinetic cutoff12. Выбраны те же допустимые осциллирующие нетермальные

```
fχ(E)=expit[-E+0.3sin(4E)]
fℓ(ω)=expit[-ω+0.3cos(4ω)].
```

Сравнение с исходным **непроецированным** continuous-occupation 5D event reference `Sdot_reference=+6.430366438×10⁻¹³`, `Qχ_reference=+2.558567329×10⁻¹³`:

| Энергетических интервалов/вид | Согласованная Sdot_bin=Sdot_event | Ошибка относительно исходного непрерывного f(E) |
|---:|---:|---:|
| 10 | +4.269218391×10⁻¹⁴ | **−93.36%** |
| 20 | +8.019647525×10⁻¹⁴ | −87.53% |
| 40 | +1.938153454×10⁻¹³ | −69.86% |
| 80 | +5.285160749×10⁻¹³ | −17.81% |
| 160 | +6.037665127×10⁻¹³ | −6.11% |
| 320 | +6.341565574×10⁻¹³ | **−1.38%** |

На каждом разрешении `|Sdot_bins/Sdot_event−1|` для **внутренне согласованного** reconstructed event меньше ~4×10⁻¹⁴, а физические дискретные Nχ,Nℓ и total Q conserved до округления. В отличие от [предыдущего наивного binning](PAIRED-CHI-LEPTON-BARYCENTRIC-5D-AUDIT.md), даже N=10 не выдаёт ложную отрицательную энтропию.

**Однако** точный H theorem не устраняет alias исходного нетермального спектра: N=10 подавляет физический event entropy более чем на 90%! N=320 всё ещё имеет 1.38% разницу при **одном** nrad4 исходном Gauss и одном finite cutoff. Не следует из этого ни <2% общей ошибки collision, ни разрешённой физической Gamma_el: angular/radial/UV систематика остаётся независимо непроверенной. Более того, логит-интерполяция при f→0/1 требует аккуратного предельного источника, в текущем коде эти входы `fail closed`.
