# Аудит термодинамического равновесия и ИК-моды, 21 ноября 2026

**Исходный коммит:** ea6ec461997600d5f00bf244ea808607d40ef8dd. Исследуется существующий лабораторный численный пример с фиксированным материнским резервуаром, а не наблюдаемая космология. Микрофизическая мотивация: Wen Yin, JHEP 05 (2023) 180, https://doi.org/10.1007/JHEP05(2023)180.

## 1. Вырождение равновесия в исходной модели

Единственный процесс χ1 ↔ χ2 + φ сохраняет C=nφ−nχ2=0, если обе дочерние популяции стартуют пустыми. Материнский термальный резервуар поддерживается при μ1=0. В реализованной модели gφ=1, gχ2=4, T=1; дочери считаются безмассовыми.

При формальном тепловом равновесии μχ2=−μφ и μφ≤0. В точке μφ=0 максимальная плотность гладкой бозонной компоненты составляет ζ(3)/π²=0.121794 на T³, тогда как фермионная плотность равна 3ζ(3)/π²=0.365381. При μφ<0 бозонная плотность только падает, а фермионная растёт. Поэтому **не существует гладкого BE/FD равновесия** с C=0 при этих предпосылках. Если идеальное равновесие с нулевой модой достижимо, ему требуется n0/T³=2ζ(3)/π²=0.243587.

Это **условие формального равновесия**, не доказательство динамического возникновения BEC. Для M1>0 точно нулевой дочерний импульс недостижим в отдельном распаде матери с конечным импульсом; в текущем коде нет ни выделенной нулевой моды, ни упругого перераспределения φ. Реальная доступность такого состояния, конечные массы и другие каналы требуют отдельной кинетической проверки. Сходство прежней численности произведённых бозонов ~0.366 с плотностью теплового χ2 не означает, что система достигла равновесия.

## 2. Аудит существующей дискретизации

Исходный тест проверял BE/FD detailed balance на точных энергиях каждой реакции с E1=Eχ2+Eφ. Но действительный численный ODE-оператор разбивает каждую реакцию на четыре пары импульсных бинов и вычисляет квантовый множитель на occupation соответствующих бинов. Для отдельной пары сумма средних энергий бинов обычно **не равна** E1, хотя средняя энергия после взвешенного переноса сохраняется.

На независимой репликации квадратур и интерполяции вычислена нормированная невязка **Σi |dnφ,i/dt| / Rvac** при BE/FD распределении и μφ=μχ2=0. Здесь Rvac — интегральная скорость прямого распада при пустых дочерних состояниях.

| Nq / Np / Nμ | Исходная L1-невязка / Rvac | Контроль с термически сбалансированной обратной скоростью |
|---|---:|---:|
| 50 / 64 / 48 | 0.116688 | <3e−16 |
| 100 / 140 / 72 | 0.028905 | <3e−16 |
| 150 / 180 / 96 | 0.012856 | <3e−16 |
| 180 / 240 / 120 | 0.008919 | <3e−16 |

Контроль заменяет только множитель обратной скорости (1−f1) на f1 exp(q̄φ,i+q̄χ2,j), так что BE/FD распределение становится точно стационарным в каждом бине при μφ+μχ2=0. **Контроль не является проверенной физической дискретизацией:** он изменяет сеточную обратную реакцию. Он лишь доказывает, что самосогласованный сеточный detailed balance можно проверить независимо от непрерывного равновесия.

Исходный оператор сохраняет инвариант разности числа дочерних частиц и барицентрическую энергию в среднем по событиям, но это не гарантирует дискретного детального равновесия. Уменьшение невязки при измельчении сетки не заменяет тест сходимости неравновесного спектра. Прежние ~769-кратное усиление и 21.8%-ный разброс среднего импульса остаются результатами указанного условного расчёта, **не физическим CLASS initial condition**.

## 3. Очерёдность дальнейших исследований

1. Сопоставить независимо две структурно-корректные схемы квантового 1↔2 оператора: сохранение дочернего инварианта, энергетическая проекция, positivity/Pauli bounds, стационарное семейство и дискретная энтропия; не принимать диагностическую перевесовку за окончательное решение.
2. Отдельно изучить предел qmin→0, возможную нулевую моду n0, доступность её реакциями и чувствительность к ИК-регуляризации; динамическая конденсация пока не продемонстрирована.
3. Только после кинетической сходимости вводить FRW, конечные массы, изменение материнского резервуара, реальные Γ/H и энергетический бюджет, затем строить физическое f(q) для CLASS и likelihood-анализа.

**Воспроизведение:** python kinetics/equilibrium_audit.py --output outputs/kinetic_equilibrium_audit.json; быстрые проверки: python -m pytest -q tests/test_kinetic_equilibrium.py. Исходный solver не меняется, CLASS и торговые программы не запускаются. Приведённая таблица основана на независимой локальной репликации; выполнение проверок непосредственно на коммите GitHub требует отдельной CI/локальной верификации.
