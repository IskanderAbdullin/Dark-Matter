# Источник 1↔2: разложение сеточной ошибки на FD-усреднение и запрещённые центры ячеек

**21 ноября 2026.** Следующий этап после [точного отделения UV cutoff от finite-cell ошибки](UV-SOURCE-DECOMPOSITION.md). В этой работе отдельно проверяется *геометрия гиперболы физического порога* в каждой ячейке и степень приближения термального FD множителя значением в центре.

**Область применимости:** первоначально пустые дочерние состояния, исходная термальная мать, \(M_1/T=0.1\). Уравнения замкнутой кинетики не изменены. Отчёт не претендует на предсказание нелинейной Bose-стимуляции и космологического freeze-out.

## 1. Интегрирование настоящего термального источника по каждой cut-cell

Для дочерних энергий \(x=q_\phi\), \(y=q_{\chi_2}\) и \(c=M_1^2/4\) физически допустимая область удовлетворяет \(xy\ge c\). Внутри любой прямоугольной ячейки \(x\in[x_l,x_h], y\in[y_l,y_h]\) число пустых распадов пропорционально

\[
I_{ij}=\int_{x_l}^{x_h}dx\int_{y_l}^{y_h}dy\,
\Theta(xy-c)\,f_F(x+y).
\]

Интеграл по y выполняется аналитически:

\[
I_{ij}=\int_{\max(x_l,c/y_h)}^{x_h}dx\,
\Big[\log(1+e^{-x-\max(y_l,c/x)})
-\log(1+e^{-x-y_h})\Big],
\]

причём диапазон пуст, если нижняя граница не меньше \(x_h\). Для численной стабильности интервал разделён на две гладкие части: **частично заполненная порогом ячейка** \(c/y_h<x<c/y_l\) и **полностью разрешённая** \(x>c/y_l\). На каждом интервале применяется Gauss–Legendre с отдельно проверяемой сходимостью 16→32 узла. Все граничные y_l=0 обрабатываются без деления на ноль.

При суммировании по **всем** ячейкам это должно совпадать с независимым точным continuum источником на квадрате \((0,Q)^2\) из [предыдущего отчёта](UV-SOURCE-DECOMPOSITION.md). В регрессионных тестах дополнительно сравнивается каждый отдельный локальный integral с независимым прямым двумерным dblquad на маленькой тестовой сетке.

## 2. Физически разные источники finite-cell ошибки

Исторический замкнутый резонансный оператор добавляет не все положительные cut-cell, а только те пары, чьи **центральные дочерние энергии** сами удовлетворяют \(4e_i e_j\ge M_1^2\). Это требуется для того, чтобы у дискретной реакции существовала настоящая on-shell мать с \(E_1=e_i+e_j\). При малом x и большом y прямоугольник может частично содержать физические события, хотя его пара центров **не** разрешена; весь вклад тогда отбрасывается.

Обозначим \(I_{\rm allowed}\) — сумму интегралов всех ячеек с разрешёнными центрами, а \(I_{\rm omitted}\) — сумму оставшихся положительных cut-cell. Их сумма равна полному непрерывному источнику внутри \((0,Q)^2\). Сеточный источник из оригинального finite-cell алгоритма \(R_{\rm sampled}=\sum_{ij}K_{ij}f_F(e_i+e_j)\) отличается по двум независимым причинам:

\[
\frac{R_{\rm sampled}-R_{\rm rectangle}}{R_{\rm rectangle}}=
\underbrace{\frac{R_{\rm sampled}-C I_{\rm allowed}}{R_{\rm rectangle}}}_{\text{ошибка FD в центрах разрешённых ячеек}}
-
\underbrace{\frac{C I_{\rm omitted}}{R_{\rm rectangle}}}_{\text{непредставленные физические события}},
\qquad C=\frac{g_1M_1}{2\pi^2}.
\]

Вторая компонента не положительна и физически соответствует **искусственному исключению части настоящего on-shell фазового пространства**. Первая может иметь любой знак: occupation у центральной энергии — не точное среднее распределение по положительной площади cut-cell.

Это разложение чисто диагностическое, оно не предполагает математически недопустимого возвращения центр-запрещённых реакций путём простого изменения \(K_{ij}\). Для их корректной репрезентации необходимо **перестроить резонансные узлы или интеграционную формулу**, оставив физическую энергию матери и два числовых инварианта, Pauli positivity и H-теорему.

## 3. Независимые проверочные условия

Новый модуль [cut_cell_gain_diagnostic.py](cut_cell_gain_diagnostic.py) автоматически:

1. Вычисляет исходный источник \(R_{\rm sampled}\) при изначально пустой φ и χ2.
2. Интегрирует настоящий FD source по всем прямоугольным cut-cell без центральной on-shell маски.
3. Проверяет совпадение с независимым прямоугольным continuum integral.
4. Разделяет вклад разрешённых центров и физически допустимых, но отброшенных cut-cell; проверяет тождество суммы ошибок.
5. Уточняет Gauss–Legendre 16→32 и проверяет локальные значения прямым двумерным интегралом на независимой маленькой сетке.

Разные верхние cutoffs 5T,7T,8.5T,10T служат отдельной осью проверки. Даже маленькая ошибка нулевой скорости **не** означает сходимости полной нелинейной фазы, нулевой моды или CLASS PSD.
