# Строгая кинематическая невозможность перенести неизменный резонансный граф 1↔2 в FRW

**21 ноября 2026.** После [аналитического massive χ1 Liouville](FRW-COLLISIONLESS-MOTHER.md), [finite-volume проверки матерей](FRW-MOTHER-FINITE-VOLUME.md) и [переменного gstarS](FRW-ENTROPY-RELEASE.md) выявлено фундаментальное препятствие прямому переносу **успешно работающего замкнутого плоского Schur-BDF решателя** в расширяющуюся Вселенную.

## 1. В чём именно противоречие

Плоская резонансная сетка была корректной при **одном** фиксированном отношении \(x_0=M_1/T\): для каждой разрешённой тройки \(i,j,k\)

\[
E_{1,k}(x_0)=e_{\phi,i}+e_{\chi_2,j}.
\]

Если материнский фермион свободно летит в FRW при постоянном \(g_{\star S}\), сохраняется его настоящий комовинговый импульс

\[
q_{1,k}=\sqrt{E_{1,k}^2(x_0)-x_0^2}.
\]

На более поздней температуре \(x=M_1/T\) его энергия **обязательно** становится

\[
E_{1,k}(x)=\sqrt{q_{1,k}^2+x^2}
=\sqrt{E_{1,k}^2(x_0)-x_0^2+x^2}.
\]

При этом фиксированные комовинговые импульсы безмассовых дочерних частиц имеют неизменную сумму \(e_{\phi,i}+e_{\chi_2,j}=E_{1,k}(x_0)\). Значит, для старого канала энергетическая невязка равна

\[
\boxed{
\Delta E_{ijk}(x)=
\frac{x^2-x_0^2}
{\sqrt{E_{1,k}^2(x_0)-x_0^2+x^2}+E_{1,k}(x_0)}.
}
\]

При \(x\ne x_0\), положительных массах и конечных энергиях **все исходные ненулевые каналы имеют ненулевую физическую энергетическую невязку**. Уточнение временного шага, более точный Jacobian или лучшее сохранение старой *дискретной энергии* не решают эту проблему: источник перестаёт быть on-shell для живых частиц.

При переходе x0=.1→x=.2 (а T вдвое ниже) у материнской энергии E1/T=.2 получаем Enew≈.264575 и \(\Delta E\approx+.064575\): наивный старый канал ошибается по энергии на 32.3% относительно своей изначальной энергии. Для E1/T=1 ошибка меньше, около 1.49%, но тоже **не ноль**. При дальнейшем охлаждении часть изначальных дочерних пар уже не удовлетворяет даже новому кинематическому порогу \(4e_\phi e_{\chi_2}\ge x^2\).

Это строгий algebraic no-go именно для **неизменного** набора резонансных пар матери и дочерних частиц, не запрет на сам распад χ1↔χ2+φ в расширяющейся Вселенной.

## 2. Новый независимый машинный аудит

Модуль [frw_resonance_drift.py](frw_resonance_drift.py) берёт уже проверенную adaptive bridged mesh с тремя настоящими инвариантами при x0=.1, восстанавливает материнские постоянные комовинговые импульсы \(q_{1,k}\) и измеряет при x=.1,.11,.2,.5,1,2:

- максимум/минимум энергетической невязки всех активных каналов;
- точную проверку рационализированной аналитической формулы для \(\Delta E\);
- число старых каналов, которые остаются **строго энергетически резонансными**;
- долю старых каналов, теперь запрещённых текущим кинематическим порогом;
- условную weighted relative energy mismatch, взвешенную исходными **вакуумными** реакционными коэффициентами для демонстрации масштаба ошибки.

Это **контрфактическая проверка** повторного использования устаревшего графа, не реальный физический FRW источник. Последняя величина не является измеренной потерей энергии в космологии.

Тесты проверяют знак невязки (x>x0 положительный, x<x0 отрицательный), нулевую невязку при x=x0, потерю точного резонанса для x≠x0 и численное тождество энергетической формулы.

## 3. Обязательное требование к следующему solver

Будущий самосогласованный FRW-алгоритм НЕ может просто заменить Γ→Γ/H, x(t) и пересчитать T внутри существующего **фиксированного энергетического** BDF ядра. Он должен:

1. Хранить χ1 на **физически постоянном комовинговом импульсе** \(q_1=p/(T\,g_{\star S}^{1/3})\), с корректным фазовым объёмом и Liouville-работой давления.
2. Для каждого x строить новые физически on-shell реакции и правильно связывать мать с **моментальной** суммой энергий дочерних частиц; их набор/веса меняются во времени.
3. Реализовать неизбежное перемещение/интерполяцию между матерью и дочерьми без отрицательных occupation, нарушения Pauli, двух зарядов, физического общего энергетического баланса или порождения ложных инвариантов.
4. Проверять Γ→0 против [FRW-COLLISIONLESS-MOTHER.md](FRW-COLLISIONLESS-MOTHER.md) и [FRW-ENTROPY-RELEASE.md](FRW-ENTROPY-RELEASE.md), а H→0 против замкнутого плоского Schur-BDF, не путая совпадение в одном предельном случае с корректностью полного переноса.
5. Только после такого каркаса добавлять реальный SM exchange, gstar таблицы, конечные массы, zero-mode/конденсат и CLASS.

Такая конструкция остаётся существенной **нерешённой инженерно-теоретической задачей**. Мы не заявляем, будто уже есть готовый реалистичный FRW χ1↔χ2+φ kinetic solver или физический freezeout 86-эВ частиц.
