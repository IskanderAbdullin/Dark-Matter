# Консервативный перенос материнского распределения между движущимися FRW-сетками

**21 ноября 2026.** Этап после [точного запрета на повторное использование плоских резонансов в FRW](FRW-RESONANCE-DRIFT.md). Модуль [parent_q_remap.py](parent_q_remap.py) реализует отдельно **collisionless Liouville-перенос** массивной матери между энергетическими разбиениями, изменившимися из-за роста отношения x=M1/T.

Для постоянного g*S физически сохраняется комовинговый импульс q=p/T. Пусть u=q³, а fermion occupation f_i постоянна по каждому исходному объёму. Новая occupation вычисляется из точного перекрытия ячеек в фазовой мере:

\[
f_j^{\rm new}=\frac{\sum_i f_i^{\rm old}\,
 |[u_i,u_{i+1}]\cap[v_j,v_{j+1}]|}
{v_{j+1}-v_j}.
\]

При **совпадении глобального диапазона** это точный по числу finite-volume перенос в рамках принятого кусочно-постоянного представления. Новые occupations — выпуклые комбинации старых: 0≤f≤1 соблюдается, а комовинговое число n/T³ сохраняется. Дискретная фермионная энтропия не уменьшается при огрублении (неравенство Йенсена). Алгоритм двух указателей линейный по количеству исходных и новых бинов; не строит плотную матрицу пересечений для нескольких тысяч матерей.

**Это не энергосохраняющий remap.** Физическая энергия конечного q-бина при x вычисляется независимо положительной Gauss-квадратурой, и код сообщает конечную численную энергоошибку до/после проекции при **том же самом x**. Её нельзя выдавать за физическую работу давления и нельзя спрятать искусственным изменением occupation; в будущей FRW-интеграции следует учесть её в численном energy-budget и провести сеточную сходимость. Формально точное сохранение числа и Pauli не гарантирует правильность энергии и entropy production.

Программа также строит две parent-q сетки из одних energy-centers E_k, на x=x0 и x=x1, если все представляющие энергопозиции матери остаются выше новой массы. При пересечении порога E_k<x1 останавливается: нужно перестроить on-shell кинетическую сеть, а не пересадить запрещённую материнскую моду на фиктивный импульс.

Регрессионные проверки: точный аналитический пример усреднения f=1 на 0<q<1 и f=0 на 1<q<2 в один бин (fnew=1/8), тождественный перенос, постоянная occupation, случайные сильно неравномерные q-сетки, число, Pauli, дискретная энтропия, конечная энергия, ошибочные диапазоны и физическая смена материнского порога.

**Научный статус:** это только численно и аналитически проверенный Liouville-компонент. Не выполнены одновременные collision+FRW equations с новой on-shell сетью, точный общий энергетический бюджет, переменный g*S, динамическая нулевая мода и CLASS. Следующий этап — замкнутый split-step диагностический benchmark и оценка накопления проекционной ошибки.

Запуск: python kinetics/parent_q_remap.py; python -m pytest -q tests/test_parent_q_remap.py.
