# Симметричное collision–Liouville–collision разбиение в короткой FRW-эволюции

**21.11.2026.** После отрицательной проверки 25.66% при удвоении числа шагов в [первом Lie collision+Liouville split](NARROW-CLOSED-FRW-SPLIT.md) реализован независимый **симметричный** вариант для проверки источников временной ошибки. Этот этап не означает, что задача со сходимостью решена: схема имеет x-зависимые пороги, и формальный второй порядок Strang не следует автоматически из обычного доказательства для гладких операторов.

Новый модуль [strang_frw_split.py](strang_frw_split.py) сравнивает два способа интегрирования тех же физических исходных данных:

- **Lie:** полный collision(x_left) с затем conservation-q³ Liouville remap матери на x_right.
- **Symmetric:** половинный collision(x_left), затем conservation-q³ remap, затем половинный collision(x_right).

Масштаб времени задан одним RD \(H(T)=H(M_1)/x^2\), так что \(\Delta(t\Gamma)=\kappa(x_{\rm right}^2-x_{\rm left}^2)/2\). На обеих половинах пересобирается настоящий on-shell collision graph с актуальной массой M1/T; все фермионные и бозонные компоненты динамические, материнская occupancy единая на каждой текущей энергии. В новой версии также возможно изменение набора уникальных материнских энергоцентров при сохранении настоящего комовингового q и числовых зарядов.

Для каждого шага записываются **раздельно** две невязки дискретной энергии collision half-steps, две физические ошибки представления parent energy, настоящая collisionless FRW-поправка к энергии и чистая ошибка q³-проекции матери. Ни одна из этих величин не «поправляется» искусственным изменением f(q) ради точного энергетического баланса; если полная физическая энергия не соблюдается, статус результата не является CLASS-ready.

**Критерий оценки:** автоматический опыт при x=.0200→.0202, κ=500 сопоставляет число φ после 2 и 4 шагов *в обеих схемах*, выводя численную относительную разницу, а также честный диагностический флаг, оказалась ли симметричная схема в этом тесте лучше. Код НЕ содержит предположения, будто Strang обязательно улучшит accuracy в присутствии движущихся реакционных порогов и сеточного перемешивания. На следующем этапе необходим скан 4→8→16 шагов по x, разные κ и независимые IR/UV сетки.

Воспроизведение: python kinetics/strang_frw_split.py; python -m pytest -q tests/test_strang_frw_split.py.

Это физически ограниченный **структурный** пилот: условно заданный RD фон, постоянный g*S, узкий промежуток, сильно обрезанная термальная мать и неустранённая physical shell-energy error. Нет self-consistent SM energy exchange, конечных дочерних масс, zero-mode BEC и наблюдательно готового freeze-out спектра.
