## Почему BEST особенно ценен

BEST принципиально отличается от наших finite-cell резонансных sumset-решателей: авторы реализовали общий momentum-resolved Boltzmann solver с полными квантовыми Bose/Pauli факторами, несколько динамических видов, точную кинематику после обновления 1.3.x, FRW-расширение, stiff integrators и специализированное представление zero mode. Внешние примеры examples/Mdecay.py и examples/inflaton_bec.py имеют проверяемые режимы динамического рождения/распада и нулевой моды, scripts/check_custom_term.py сравнивает собственный аналитический интеграл 1↔2 с Vegas, scripts/check_zero_mode.py тестирует энергию и детальное равновесие конденсатных членов. Это не доказывает автоматически применимость BEST к нашей модели с массой 86 эВ, но делает независимую проверку значительно реалистичнее.

**Разница статьи и версии:** оригинальная статья содержит иные схемы регуляризации energy delta; текущий BEST v1.3.5 README и CHANGELOG явно заявляют генерацию **точной двухчастичной кинематики**, что надо проверять по актуальному коду, не по старому описанию статьи.

## Строгая первая точка сравнения: производная числа при пустых дочерьми

В расчётных единицах T=1, Mχ1=.1, Γrest=1, gχ1=4, gφ=1, gχ2=4. Вначале χ1 — тепловая Fermi–Dirac, обе дочери φ и χ2 пустые, статистики Bose и Fermi соответственно. Сравнивать только **мгновенные** derivative числа, без движения по космологическому времени. Независимый 1D on-shell континуальный эталон:

\[
R_{\mathrm{vac}}=\frac{g_{\chi_1}M_{\chi_1}\Gamma}{2\pi^2}
\int_0^\infty dq\,
\log\left(1+\exp[-q-M_{\chi_1}^2/(4q)]\right)
=\boxed{0.0164959084596}.
\]

Наиболее распространённая ловушка — внутренняя нормировка спинов. BEST README и examples/Mdecay.py указывают, что matrix-element squared **просуммирован по всем внутренним состояниям**, а BEST сам делит на dof наблюдаемой частицы. Для безмассовых дочерей использовать в протоколе \(\sum|M|^2=16\pi M_{\chi_1}\Gamma g_{\chi_1}\), что прямо соответствует примеру в BEST.

После действительно внешнего исполнения проверять сразу три независимые реакции числа:

\[
\dot n_\phi=\dot n_{\chi_2}=-\dot n_{\chi_1}=R_{\rm vac}.
\]

Результат от BEST интегрировать **его собственными** весами grid_weights(q) с q², физическими dof и коэффициентом 1/(2π²). Должна быть независимая сходимость по нижнему/верхнему импульсу, числу бинов и neval Vegas (как минимум два значения каждого), поскольку конечная q-сетка и Monte Carlo могут ошибаться. Строгий допуск нельзя объявить до получения статистического разброса.

## Как воспроизвести

Внешний проект установить **отдельно**, не копировать BEST в наш репозиторий:

    git clone https://github.com/best-hep/best.git
    cd best
    git checkout c70875be714e7a6bc6d38578c34bb0dc9f5aefa9

Установить зависимости numpy/scipy/mpi4py/vegas по официальному README BEST. Затем в нашем проекте:

    python kinetics/best_external_vacuum_reference.py --protocol
    mpirun -np 2 python kinetics/best_external_vacuum_reference.py --execute --best-root /path/to/best --output outputs/best_vacuum.json

Важное техническое ограничение: скрипт сохраняет ожидаемый pinned SHA, но **не проверяет автоматически настоящий Git HEAD внешней директории**; перед научной интерпретацией нужно выполнить git rev-parse HEAD и записать его рядом с экспериментом. Пустой protocol или unit tests НЕ означают, что внешний solver действительно исполнялся.

## Следующий научный критерий

После первого внешнего vacuum-источника: (1) finite nonzero occupations и полное gain/loss вместе с обратной реакцией, (2) плотная сетка qmin и отдельная zero-mode для сценария stimulated burst, (3) самосогласованная динамическая мать + плазма, (4) настоящие FRW energy/entropy/number budgets и реальная микрофизическая Γ, (5) только после замороженного и сходящегося f(q) — CLASS и observational likelihood. Ничего из этого нельзя заменить одним совпавшим числом Rvac или заявлением о Bose condensation.
