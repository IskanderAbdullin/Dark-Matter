# Первый реальный независимый BEST Monte Carlo — GitHub Actions

**Цель:** впервые получить внешний rate pass по χ1↔χ2+φ из отдельного BEST v1.3.5 вместо одних аналитических протоколов и синтетических фикстур. Работает в **публичном** репозитории в отдельной исследовательской ветке и не изменяет main.

Workflow: [.github/workflows/best-independent.yml](../.github/workflows/best-independent.yml). Автоматический запуск ограничен изменениями workflow и BEST-модулей, возможен ручной запуск. Job ограничена 20 минутами, JSON хранятся 7 дней, GitHub token имеет только contents:read, нет push/deploy.

Runner: Python 3.11, openmpi-bin/libopenmpi-dev, pip numpy/scipy/mpi4py/vegas. Внешний BEST клонируется в /tmp/best, **строго checkout SHA c70875be714e7a6bc6d38578c34bb0dc9f5aefa9** и независимо проверяется до импорта. Сначала выполняется MPI smoke с двумя процессами.

Первый эксперимент минимальный: **28 q-точек**, Vegas neval=3000, Γrest=1, M1/T=.1, χ1 thermal FD g=4, пустая φ Bose g=1, пустая χ2 FD g=4. Измеряются три интегральных производных **числа и энергии** и **дифференциальная форма** рождения φ. Самостоятельный аналитический эталон:

- dnphi/dt = dnchi2/dt = −dnchi1/dt = 0.0164959084596;
- −drho_chi1/dt = drho_phi/dt + drho_chi2/dt = 0.03646818570688685;
- максимум dRphi/dq при q=M1/(2T)=0.05.

Строгий смысл первой попытки: проверить, что отдельный независимый код действительно может выполниться и предоставить данные. **Одна грубая q-сетка и одно число neval не устанавливают сходимость**, даже если некоторые числа близки к эталону. Comparator обязан вернуть source_agreement_verified=false.

Диагностические artifacts хранятся максимум 7 дней и **не коммитятся автоматически**. Следующие этапы: по крайней мере две сетки, два neval, независимые random seeds, статистические и систематические погрешности. При падении workflow необходимо изучить отрицательные логи и исправить процесс; нельзя объявить BEST согласованным без успешного исполнения.

**Статус до реального успешного артефакта:** внешнего численного сравнения ещё нет. Ни успешный smoke, ни несколько rates не валидируют нелинейный freeze-out, физический спектр 86-эВ тёмной материи или CLASS.


## Первый независимый реальный результат — УСПЕШНО выполнено

[GitHub Actions run #44915936135](https://github.com/IskanderAbdullin/Dark-Matter/actions/runs/44915936135) действительно завершился успешно: BEST клонирован и проверен по Git SHA, Python 3.11 + MPI успешно видят два процесса, а нулевой квантовый источник реально вычислен **в коде BEST**, не в наших тестовых фикстурах. Исходные BEST-JSON опубликованы как отдельный краткосрочный artifact этой Actions run.

Тестовые параметры: 28 log-q узлов, neval=3000, две MPI задачи, M1/T=.1, Γrest=1, g1=4, пустые дочери. Численные измерения **без утверждения о сходимости**:

| Производная | BEST | Точный континуальный эталон или закон |
|---|---:|---|
| dnχ1/dt | −0.016494938895 | −0.016495908460 |
| dnφ/dt | +0.016491105467 | +0.016495908460 |
| dnχ2/dt | +0.016491544714 | +0.016495908460 |
| dρχ1/dt | −0.036612745848 | −0.036468185707 |
| dρφ/dt | +0.018233789707 | Дочери вместе должны получить +0.036468185707 |
| dρχ2/dt | +0.018232020273 | Дочери вместе должны получить +0.036468185707 |

Отклонение φ number от точного источника **−0.02912%**, модуль энергетической потери χ1 от эталона **+0.3964%**, сумма всех трёх энергетических производных **−0.000146935868**. Это реальные конечносеточные / Monte Carlo расхождения, которые не исправлялись искусственной нормировкой. Pointwise φ dR/dq RMS-ошибка в единицах аналитического максимума **0.00024256**, максимум локальной относительной ошибки на устойчивом участке источника **0.3182%**. q-пик на сетке 0.04336 вместо непрерывного 0.05.

**Следующий запуск workflow** уже настроен на проверку двух q-сеток (28 и 56), двух neval (3000 и 12000), и отдельное реальное вычисление thermal Bose/Pauli detailed balance при ненулевых occupations. Он должен отделить предельную ошибку интегрирования от Monte Carlo fluctuations; даже успешное предварительное сравнение не означает сходимость в неравновесном FRW или расчёт тёмной материи.

Данный завершённый настоящий внешний smoke **исправляет прежний исторический статус «BEST не исполнялся»**: для начального vacuum источника BEST уже исполнен, а для обратных распадов/FRW на этот момент нет.
