# Устранение ложных интегралов движения при росте M1/T: динамический аудит UV-сетки

**21.11.2026.** Предыдущий [FRW mode crossing pilot](FRW-MODE-CHANGES.md) прошёл только x=.020→.022; к x≈.025 разреженная daughter grid верхней энергией 0.3005T приобретает лишние collision invariants. Это не дефект физического распада: на данной сетке ряд мягких и энергичных дочерних мод перестаёт быть связан общими материнскими резонансами.

Новый модуль [dynamic_rank_uv_repair.py](dynamic_rank_uv_repair.py) независимо пересоздаёт **мгновенную** on-shell сеть для каждого x=M1/T и ищет минимальную верхнюю энергию из заданного набора \(R_{\max}\), при которой ядро линейных реакционных инвариантов имеет ровно размерность 3, а изолированных дочерних мод нет.

Конструкция: дочерние энергетические узлы e_i/T=(i+0.5)δ, δ=.001, индексы 0..99 и дополнительные 50,100,...,Rmax. Для каждого разрешённого \(4e_i e_j\ge x^2\) канала учитывается один общий материнский E1=e_i+e_j. **Это rank-аудит на фиксированном x, а не доказательство физической сходимости kinetic source.**

| x=M1/T | Минимальный проверенный Rmax | Верхний дочерний q/T приблизительно | Инварианты после ремонта |
|---:|---:|---:|---:|
| .020 | 300 | .3005 | 3 |
| .025 | 400 | .4005 | 3 |
| .030 | 500 | .5005 | 3 |
| .040 | 1000 | 1.0005 | 3 |
| .050 | 1500 | 1.5005 | 3 |
| .080 | 3500 | 3.5005 | 3 |
| .100 | 5000 | 5.0005 | 3 |

Эти границы — **результаты поиска в данном дискретном списке**, а не истинные математически минимальные qmax и не универсальный выбор сетки. При другом числе IR-узлов/шаге, материнской массе или квантовом ядре вывод может измениться.

**Главное предупреждение:** самая компактная сетка, на которой остаётся ровно три инварианта, всё равно может очень плохо передавать начальные number/energy/pressure Fermi–Dirac моменты χ1. Поэтому после подбора по graph rank выполняются ещё **независимые** одномерные континуальные FD интегралы и отчёт включает относительные ошибки трёх моментов. Физический критерий допускa к CLASS требует гораздо большего: source/quadrature accuracy, динамической сходимости по q/времени, full FRW energy closure и zero-mode.

Эта работа показывает практическое направление преодоления порога x=.025: **синхронно расширять сетку дочерних частиц и переносить физические популяции, сохраняя комовинговые заряды**. Сам алгоритм физически корректного daughter remap и восстановления общего energy/H-теоремы пока не написан; нельзя просто добавить новые пустые дочерние бины и считать, что получено решение.

Воспроизведение: python kinetics/dynamic_rank_uv_repair.py --quick; полный режим без --quick; python -m pytest -q tests/test_dynamic_rank_uv_repair.py.
