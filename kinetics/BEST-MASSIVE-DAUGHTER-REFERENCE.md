# Реальная независимая проверка ненулевой массы бозона в BEST v1.3.5

После аналитического расчёта [MASSIVE-DAUGHTER-SOURCE.md](MASSIVE-DAUGHTER-SOURCE.md) добавлен отдельный **опциональный запуск внешнего BEST** для χ1→φ(mφ)+χ2(mχ), с ненулевой массой φ. Требуется настоящий pinned BEST, подтверждённый через git rev-parse HEAD, и отдельная установка MPI/Vegas. Сам исходный проект BEST сюда **не копируется**, старые реализации не заменяются.

Ключевой момент нормировки: раньше для двух безмассовых дочерей мы задавали BEST spin-summed amplitude \(g_1\,16\pi M_1\Gamma\). При ненулевых массах дочерей и условии **неизменной собственной ширины** Γrest=1 правильный параметр должен измениться:

\[
\boxed{\sum_{\rm all\,spins}|\mathcal M|^2 =
g_{\chi_1}\,\frac{8\pi M_1^2\Gamma_{\mathrm{rest}}}{p^*}},
\]

где \(p^*\) — настоящий покойный импульс из точной функции Кэллена. Именно при \(p^*=M_1/2\) вновь получается прежний massless \(16\pi M_1\Gamma g_1\). Если ошибочно использовать старую матрицу на массивной φ, BEST **справедливо** даст другую Γ из-за уменьшения фазового объёма. Наша проверка удерживает Γ постоянной исключительно для сравнения аналитической кинематики; это ещё НЕ конкретный физический лагранжиан.

Скрипт [best_massive_daughter_reference.py](best_massive_daughter_reference.py) при запросе --execute запускает BEST на τ=0 (до любой кинетической эволюции), строит **непрерывный физический** φ dR/dq и сравнивает с независимо выведенной точной формулой. Также проверяются три числа dns/dt, три физические energy fluxes, доля энергии φ в распаде, положительные q-occupation derivatives и q→0 физический предел, выведенный **аналитически**, а не экстраполированный из отсутствующей в сетке точки q=0.

Важное предупреждение: BEST содержит специальную нулевую моду для **массивного бозона**. Однако конечный small-q grid point BEST **не является** макроскопическим конденсатом n0. Сопоставление qmin и \(df_\phi(q_{\min})/dt\) с аналитической функцией не доказывает появления n0, самосогласованной конденсации или физической 86-эВ массы. Масса mφ/T=.001 при M1/T=.1 использована как только **условный ratio mφ/M1=.01**, который в настоящем лагранжиане ещё предстоит установить.

Воспроизведение без внешнего запуска:

    python kinetics/best_massive_daughter_reference.py
    python -m pytest -q tests/test_best_massive_daughter_reference.py

Внешний настоящий запуск:

    mpirun -np 2 python kinetics/best_massive_daughter_reference.py --execute --best-root /tmp/best --mphi .001 --grid-n 96 --neval 24000 --output outputs/best_massive_phi_96.json

Дополнительно нужно сканировать r=mφ/Mχ1=.01 и .1, qmin=1e-4 и меньше, расширять grid count и Vegas neval. Даже идеальная начальная mass-vacuum кинематика не даёт решения нелинейной Bose stimulation, полной FRW/SM энергетики, настоящей zero mode, ΩDM и CLASS — допуск к физическим выводам всё ещё **закрыт**.
