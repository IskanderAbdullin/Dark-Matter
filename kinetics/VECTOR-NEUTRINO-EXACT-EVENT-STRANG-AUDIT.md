# Точная элементарная Bose/Pauli реакция и симметричное Strang-расщепление: независимый численный аудит (2026-11-22)

## Проверяемый вопрос и научные границы

В [предыдущем эксперименте](VECTOR-NEUTRINO-CONSTRAINED-EQUILIBRIUM-AUDIT.md) удалось эволюционировать раздельные неравновесные спектры `f_ν(k)`, `f_antiν(k)`, `b_V(E)` без принудительной нейтринной FD-термализации. Однако последовательные **неявные backward-Euler события** сохраняют C/L/E и энтропию, но дают заметную, иногда немонотонную ошибку времени. Предварительная гипотеза: вычислять **точный поток каждого отдельного quantum-события**, а затем применять палиндромное Strang-расщепление; проверить измеряемый второй порядок там, где dt уже разрешает жесткие каналы.

Критерии: независимая высокоточная интеграция одного Riccati-события, 3+ временных разрешения относительно зафиксированной мелкой сетки, полные вектор/ν/antiν спектры, квантовые ограничения `b≥0`, `0≤f≤1`, истинные дискретные C/L/E и неубывание S. **Отрицательный результат при грубом dt/h необходимо сохранить**, а не скрывать успешной сохранностью инвариантов. Это численный метод для *ограниченного Z′↔ν+antiν*, не физическая χ Γ_el и не модель 86 эВ.

## Вывод точного локального оператора

Использована half-offset энергия нейтринных дочерей и положительные exact-angular overlap weights с clipped vector `E sqrt(E²−mV²)` cell. Для каждого разрешённого `V_j↔ν_i+antiν_l` пусть `B=b_j`, `F=f_i`, `A=f_lbar` и физические положительные интегральные веса `wV,wF,wA`. Определим extent `x`: `b=B−x/wV`, `f=F+x/wF`, `a=A+x/wA`. Микроскопический forward-minus-inverse Pauli/Bose flux

```
J(x) = b (1-f)(1-a) − (1+b) f a
     = q0 + q1*x + q2*x*x
q0 = B*(1-F-A) - F*A
q1 = -[B*(1/wF+1/wA)+(1-F-A)/wV+F/wA+A/wF]
q2 = (1/wF+1/wA)/wV-1/(wF*wA)
dx/dt = W * J(x)
```

Это **точное Riccati уравнение одного микрособытия**, а не BGK и не произвольный relaxation constant. Для `D=sqrt(q1²−4q2 q0)`, `r1=2q0/(D−q1)`, `r1/r2=(-q1−D)/(D−q1)`, его начальное `x(0)=0` решение:

```
x(t) = r1 * [1-exp(-D W t)] /
              [1-(r1/r2)*exp(-D W t)] .
```

`expm1` предотвращает отмену при малом времени; `D>0` проверяется, при нарушении физического интервала корень отклоняется, **нет silent clipping**. В каждой elementary 1↔2 реакции `E_V=kν+kantiν`, поэтому `C=Nν+Nantiν+2NV`, `L=Nν−Nantiν`, `E` сохраняются точно как линейные функционалы. `ln(F/R)` является градиентом общей квантовой энтропии вдоль extent; точный диссипативный микропоток не уменьшает её. Степени свободы: gV=3, gν=2, gantiν=2. `Γ0=1` — условная единица времени.

Один цикл Strang: все отдельные **точные** реакции по порядку с `dt/2`, затем в обратном порядке с `dt/2`. Палиндромность последовательности и точность локальных потоков обеспечивают формальный второй порядок **для фиксированного конечного графа** при достаточно малом dt; этот порядок нельзя автоматически переносить на неразрешённую жёсткую или континуальную задачу. Сравнение с физически и численно структурно-сохраняющими Boltzmann схемами: [Strang-splitting interpretation](https://www.sciencedirect.com/science/article/pii/S0898122111007206), [positivity and entropy constraints in deterministic Boltzmann schemes](https://www.sciencedirect.com/science/article/pii/S0021999103000652). Чужие исходники не копировались.

## Независимая проверка и измеренные числа

**Два разных численных пути**: закрытая Riccati формула в методе и независимый `scipy.integrate.solve_ivp` для шести выбранных физических событий и `dt=.02,.5,4`, `rtol=2e-11`, `atol=2e-17`. Измеренная абсолютная разница `|x_exact−x_ivp|` в этих 18 запусках не превысила **3.20×10⁻¹⁶**. Это контроль локальной формулы, а не полная независимая физическая репликация.

Параметры независимого локального прогона: `mV=.4,T=1,Emax=4,h=.2`, 207 микро-событий; одинаковые synthetic `fν=expit(-k+.15 exp(-k))`, `fantiν=expit(-k−.10 exp(-.5k))`, `bV=.75BE(E)`. `Γ0 t_end=4`. Сравнение полного спектрального максимума ошибки с **Strang dt=1/256**:

| Схема | dt | max абсолютная ошибка по всем трем спектрам |
|---|---:|---:|
| direct event-forward | 0.0625 | 0.01257733 |
| direct event-reverse | 0.0625 | 0.01487057 |
| Strang | 0.0625 | 0.00727514 |
| Strang | 0.03125 | 0.00209798 |
| Strang | 0.015625 | 0.00052151 |
| Strang | 0.0078125 | 0.00010547 |

Узкий dt-диапазон `0.0625→0.03125→0.015625` даёт отношение ошибок **3.47 и 4.02** при последовательном делении dt на два (при конечном reference dt=1/256). При h=.4, dt=.125/.0625/.03125, аналогичные ошибки `0.0017442/0.0004549/0.0001137`, соответствующие ~второму порядку.

Дискретные `C,L,E` после каждого целого прогона отличаются от исходных не более порядка **10⁻¹⁵** (h=.2), общая энтропия положительно выросла, `min ΔS_step>0`, все тестовые fermion occupations остались в [0,1] и bosons неотрицательны. Проверены два независимых способа задать химический stationary point, включая ненулевые `μν`, `μantiν`; обратная `νantiν→V` реакция рождает bosons из изначально пустого `bV=0`.

**Отрицательный контроль: жёсткость при уменьшении h.** При h=.1, `Emax=4`, уже 808 реакций; относительно dtref=1/256 ошибки Strang для dt=.125,.0625,.03125 равны **0.0232120, 0.0141676, 0.0072225** — это **ещё не** асимптотический второй порядок. Сохранение C/L/E и энтропии не устраняет недоразрешённую жёсткость. Отдельно прежние конечносеточные проблемы: h=.05 слабый number moment −0.142%, vector threshold/bin cutoff и Emax tails; они не исчезают от лучшего time integrator. Нельзя определять физический `Γ/H` только по успешному Strang тесту.
