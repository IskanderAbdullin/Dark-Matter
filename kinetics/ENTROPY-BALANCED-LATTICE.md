**ПОСЛЕДУЮЩЕЕ УЛУЧШЕНИЕ:** построен физически on-shell оператор непосредственно в переменных энергий обеих дочерних частиц, без эффективной подмены материнской энергии исходной квадратуры. См. [новый 2D collision operator](ONSHELL-COLLISION-2D.md). Данный документ сохраняется для исторического сравнения схем и диагностики ошибки проекции.

Она меняет распределение сеточных ячеек. См. [аудит угловых пределов](ANGULAR-ENDPOINT-IR-AUDIT.md) и [улучшенное интегрирование по log q дочери](LOGQ-ANGULAR-QUADRATURE.md).

## Модель и принципиальное ограничение

Для каждой пары принимающих импульсных бинов (i,j) введена эффективная энергия материнской частицы \(E_{ij}^{\mathrm{eff}}=\bar q_{\phi,i}+\bar q_{\chi_2,j}\). Геометрическая величина \(K_{ij}\ge0\) получается из исходной квадратуры материнских импульсов и угла распада, с сохранением неотрицательных барицентрических весов.

**Мы заменяем настоящую материнскую энергию \(E_1\) в её статистическом множителе на \(E_{ij}^{\mathrm{eff}}\):**

\[
a_{ij}=\frac{1}{1+\exp(E_{ij}^{\mathrm{eff}})},\quad
J_{ij}=K_{ij}\left[a_{ij}(1-f_j)(1+b_i)-(1-a_{ij})f_jb_i\right].
\]

Одинаковый \(J_{ij}\) входит в численность каждой дочерней частицы. Эта схема не является точно дискретизированным физическим столкновительным интегралом: на конечной сетке \(E_{ij}^{\mathrm{eff}}\ne E_1\) для отдельных исходных реакций. Отчёт количественно измеряет эту ошибку, а не скрывает её.

## Выведенные и проверяемые свойства сеточной модели

1. **Точный инвариант:** \(\dot n_\phi-\dot n_{\chi_2}=0\) с ошибкой порядка округления.
2. **Статистические границы:** при \(b_i=0\) производная неотрицательна; для \(f_j=0\) — неотрицательна, при \(f_j=1\) — неположительна. Интегратор дополнительно проверяет ошибки своих шагов.
3. **Равновесие в самом сеточном операторе:** \(b_i=[\exp(\bar q_i-\mu_\phi)-1]^{-1}\), \(f_j=[\exp(\bar q_j+\mu_\phi)+1]^{-1}\), \(\mu_\phi\le0\), дают \(J_{ij}=0\) для каждой пары ячеек.
4. **Дискретная H-теорема при \(T=1\) для фиксированного резервуара:** если \(A_{ij}=K_{ij}a_{ij}(1-f_j)(1+b_i)\), \(B_{ij}=K_{ij}(1-a_{ij})f_jb_i\), то
\[
\frac{dF}{dt}=-\sum_{ij}(A_{ij}-B_{ij})\log\left(\frac{A_{ij}}{B_{ij}}\right)\le0,
\]
где
\[
F=\sum_i V^\phi_i\left[\bar q_i b_i+b_i\ln b_i-(1+b_i)\ln(1+b_i)\right]
+\sum_j V^{\chi_2}_j\left[\bar q_j f_j+f_j\ln f_j+(1-f_j)\ln(1-f_j)\right].
\]
Это утверждение **только о данной сеточной модели**, не об энтропии физического исходного источника с материнской энергией \(E_1\).

## Независимые численные проверки и границы точности

Прямой лабораторный расчёт указанной сеточной модели с \(T=1,M_1/T=0.1,t\Gamma=0.03\). Последний импульсный бин охватывает значения до 32T. Числа не являются космологическим freeze-out или спектром для CLASS.

|---|---:|---:|---:|---:|
| 50/64/48 | +3.060% | 8.092% | 0.34703 | 0.0041351 |
| 100/140/72 | +0.756% | 4.050% | 0.35994 | 0.0032287 |
| 150/180/96 | +0.336% | 2.690% | 0.36113 | 0.0029546 |
| 180/240/120 | +0.233% | 2.246% | 0.36236 | 0.0029737 |

Здесь энергетическая ошибка — средняя **абсолютная** \(\sum w|E_{ij}^{eff}-E_1|/\sum w E_1\), не относительная ошибка полной космологической энергии. Подписанная ошибка общей скорости может быть заметно меньше средних абсолютных ошибок за счёт сокращения знаков.

Независимый ИК-контроль при Nq/Np/Nμ=150/180/96:

| qmin/T | nφ/T³ | Среднее q |
|---|---:|---:|
| 1e−5 | 0.361128 | 0.002955 |
| 1e−6 | 0.361557 | 0.002866 |
| 1e−7 | 0.360764 | 0.002902 |

Точность интегральной численности на этих трех ИК-параметрах лучше ~0.25%, но изменение среднего импульса между экстремумами ~3.1%. Независимая сходимость по двум параметрам ещё не доказана; сам исходный оператор давал другой средний импульс. Высота максимальной occupation сильно зависит от сетки и не является наблюдательным предсказанием.

- Ввести конечные массы, FRW, изменение температуры/источника, Γ/H и полную плотность энергии. Только после верификации рассчитывать \(f_\phi(q)\) и CLASS.
