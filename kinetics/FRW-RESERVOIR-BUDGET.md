# Количественная проверка ограничений фиксированной материнской ванны в FRW

**21 ноября 2026.** Следующий научный аудит после [FRW-пилота](FRW-FIXED-BATH-PILOT.md). Данный шаг не подменяет самосогласованный трёхкомпонентный FRW расчёт — он выводит **необходимую верхнюю границу** на допустимое количество произведённых бозонов для любой гипотетической *замкнутой* версии этой реакции.

## 1. Строгое условие из сохранения числа

Единственная реакция χ1↔χ2+φ сохраняет a³(nχ1+nφ) и a³(nχ1+nχ2). Если в начальный момент обе дочерние популяции пусты, никакой замкнутый вариант модели при отсутствии внешних каналов и постоянном g*S не может создать больше бозонов, чем изначально было материнских частиц:

\[
\boxed{\left(n_\phi/T^3\right)_{\rm final}
\le \left(n_{\chi_1}/T^3\right)_{\rm initial}.}
\]

Это независимый от сетки, скорости распада и Bose enhancement закон сохранения *для числа*, если χ1 не может пополняться другими каналами. Если стандартная плазма преобразует SM→χ1, простая замкнутая граница больше не обязательна, но нужно явно рассчитывать поток и энергетический бюджет.

При gχ1=4, x_start=M1/T=0.05, T∝1/a, исходная термальная плотность:

\[
\frac{n_{\chi_1}}{T^3}
=\frac4{2\pi^2}\int_0^\infty
\frac{q^2\,dq}{1+\exp(\sqrt{q^2+0.05^2})}
=\boxed{0.3652061032774}.
\]

Независимая безмассовая верхняя граница при x→0 составляет 3ζ(3)/π²=0.3653814847007.

## 2. Прямое сопоставление с прежним fixed-bath FRW

Здесь внешняя термальная ванна поддерживает fχ1 неизменным, а κ=Γrest/H(T=M1) свободна. Следующие округлённые цифры из 80-ячеечного численного пилота соответствуют прежним условиям x=0.05→30.

| κ | nφ/T³ к концу | Доля исходных матерей, которую пришлось бы израсходовать в замкнутом варианте |
|---:|---:|---:|
| 0.0001 | 0.0000864 | 0.024% |
| 0.001 | 0.000864 | 0.237% |
| 0.01 | 0.008704 | 2.38% |
| 0.1 | 0.24216 | 66.3% |
| 0.2 | 0.36948 | **101.17% — невозможно без подпитки** |

При κ=0.2 исходная плотность 0.365206 меньше числа произведённых бозонов около 0.36948. Формальный **минимальный нетто-приток** матерей из внешней среды должен быть не меньше 0.00427/T³ (около 1.17% от исходного числа). Реальная термальная подпитка должна компенсировать изменения распределения и обеспечивать энергию: это только строгая числовая нижняя граница на интегрированный внешний приток.

При κ=0.1 граница не нарушается, но необходимое истощение закрытой матери было бы 66.3%; фиксировать её термальное распределение без взаимодействия с внешней плазмой нельзя считать самосогласованным. При κ=0.01 диагностический расход около 2.38%. Во всех случаях выполнение границы не гарантирует физическую или энергетическую допустимость полного сценария.

## 3. Область доказательства

- Доказано **необходимое** начальное число матерей для закрытой реакции с пустыми дочерними популяциями. Предположены постоянные энтропийные степени свободы и aT=const.
- Текущий **фиксированный источник не противоречит собственной модели**: он по построению открыт и допускает подпитку. Недопустимо только переименовать его результат в результат закрытой физической системы без этой подпитки.
- Не доказана ни динамическая конденсация, ни физическая космологическая масса бозона, ни согласие с наблюдениями. Конечная ширина распада, SM↔χ1, энергия и энтропия должны быть реализованы до CLASS.
- quoted nφ относятся к условному численному FRW-пилоту; число-инвариант математически независимо от его сеточной точности.

## 4. Код

Файл frw_reservoir_budget.py считает исходную плотность независимо одномерным интегрированием, сравнивает с κ-сценариями и выдаёт необходимую долю depletion, минимальную нетто-подпитку и признак невозможности закрытого истолкования.

Команды воспроизведения:

    python kinetics/frw_reservoir_budget.py --quick
    python kinetics/frw_reservoir_budget.py --output outputs/frw_reservoir_budget.json
    python -m pytest -q tests/test_frw_reservoir_budget.py
