# Точное нелинейное квантовое 1↔2 столкновение при ненулевых химпотенциалах

Следующий независимый тест после начального vacuum-спектра и строгого thermal detailed balance. Выведена аналитическая формула для **мгновенного** net источника рождения безмассового бозона φ из распада массивного χ1 с учётом **всех** Bose/Pauli прямых и обратных множителей. Все три частицы считаются термальными при одной фиксированной T=1, но химпотенциалы могут не удовлетворять условию химического равновесия.

При on-shell q=qφ>0, y=qχ2≥m²/(4q), Eχ1=q+y, m=Mχ1/T, распределения:

- f1=1/(1+exp(q+y−µ1)), f2=1/(1+exp(y−µ2));
- b=1/(exp(q−µφ)−1), µφ<0.

Квантовый чистый integrand равен f1(1−f2)(1+b)−(1−f1)f2b. **Химическая аффинность** Δµ=µ1−µ2−µφ входит исключительно как множитель 1−exp(−Δµ), поэтому знак чистого рождения определяется только знаком Δµ при общем T, а при Δµ=0 источники взаимно компенсируются для любой on-shell энергии.

Один интеграл по y можно **выполнить точно**. Обозначив A=exp(q−µ1), B=exp(−µ2), t=exp[−m²/(4q)], получаем

\[
\int_{m^2/(4q)}^\infty f_1(1-f_2)\,dy
=\frac{B}{A-B}
\left[\ln(1+t/B)-\ln(1+t/A)\right].
\]

При A→B правильный регулярный предел — t/(A+t). Тогда

\[
\boxed{
\frac{dR_{\rm net}}{dq}=
\frac{g_1m\Gamma}{2\pi^2}(1+b(q))\,
\frac{B}{A-B}\bigl[\ln(1+t/B)-\ln(1+t/A)\bigr]\,
(1-e^{-\Delta\mu}).
}
\]

Численно используется log1p, expm1 и отдельный A≈B предел. Плотность числа φ, χ2 и χ1 меняется с одинаковой абсолютной величиной при противоположном знаке χ1. Этот результат является **непосредственным snapshot-контрольным benchmark полного нелинейного Bose/Pauli collision kernel**, а не решением динамической Boltzmann системы.

## Проверенные численные значения

Для m=.1, g1=4, Γ=1, µφ=−.3, µ2=.1:

| µ1 | Δµ | Чистая скорость Rφ |
|---:|---:|---:|
| −.25 | −.05 | −0.000826365040388528 |
| −.20 | 0 | ≈0 (machine precision) |
| −.15 | +.05 | +0.000856502725350217 |

При µ1=0, µ2=µφ=−30 обе дочери практически пусты: точный формализм возвращается к независимому vacuum source **0.016495908459584**, как ранее был получен совсем другим способом.

Для нескольких q выполнено **независимое прямое численное интегрирование 2D on-shell** с исходными Fermi/Bose функциями (без использования замкнутой логарифмической формулы), проверены конкретные величины, знаки и регулярный предел A=B. Все эти результаты — аналитически обоснованные. Они не предполагают никакого запущенного внешнего BEST для подтверждения.

## Следующий этап

Использовать независимый BEST v1.3.5, который уже впервые реально запущен в [публичной GitHub Actions](BEST-GITHUB-ACTIONS.md), для сравнения не только пустого вакуумного источника, но и **ненулевых occupation, обратного 2→1 канала**, трёх числовых производных, физических энергетических производных и pointwise dR/dq. Кросс-проверка на двух сетках и нескольких Vegas neval нужна отдельно. Один хороший rate, даже с правильным балансом, не удостоверяет нелинейный cold burst, BEC zero-mode, физический freeze-out, ΩDM и CLASS P(k).
