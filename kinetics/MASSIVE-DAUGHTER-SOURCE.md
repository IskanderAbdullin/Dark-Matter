# Почему 86-эВ бозон нельзя безоговорочно считать безмассовым у q=0: точное двухчастичное рождение с конечной массой

**Следующий критический физический шаг** после [реального BEST нелинейного Bose/Pauli snapshot](BEST-CHEMICAL-AFFINITY.md). Раньше численные toy-ядра полагали φ безмассовой: это допустимая приближённая кинематика при pφ≫mφ, **но не обязательно при pφ→0**, где зарождение конденсата или холодного IR пика наиболее чувствительно к массе. Теперь получен точный аналитический источник первоначально пустого φ **при ненулевом mφ**, не заменяющий её массой 0 в самой низкой моде.

**Важный контекст:** физическая φ в исследуемом сценарии имеет предполагаемую массу **86 эВ**; отношение mφ/Mχ1 и температура самого рождения пока не установлены конкретным лагранжианом. Ниже переменные r=mφ/Mχ1 — **иллюстративные параметры**, не реконструкция микрофизических значений 86-эВ модели.

## 1. Точная релятивистская кинематика

Материнская χ1 массы M имеет изотропный двухчастичный распад χ1→φ(mφ)+χ2(mχ), где \(M>m_\phi+m_\chi\). В покое χ1:

\[
E_\phi^*=\frac{M^2+m_\phi^2-m_\chi^2}{2M},\qquad
p^*=\frac{\sqrt{[M^2-(m_\phi+m_\chi)^2][M^2-(m_\phi-m_\chi)^2]}}{2M}.
\]

Для конечного лабораторного \(q=p_\phi/T\), \(E_\phi/T=\sqrt{q^2+(m_\phi/T)^2}\), законы сохранения энергии и импульса ограничивают энергию матери:

\[
E_{1,\min}=\frac{M[(E_\phi^*)^2+q^2]}{E_\phi E_\phi^*+qp^*},\qquad
E_{1,\max}=\frac{M(E_\phi E_\phi^*+qp^*)}{m_\phi^2}
\quad (m_\phi>0).
\]

Формулы записаны в единицах T=1. Выражение для нижнего предела **рационализировано** во избежание катастрофического вычитания двух близких корней. При mφ=0 верхний предел стремится в бесконечность; при двух безмассовых дочерях \(E_{1,\min}=q+M^2/(4q)\), что точно восстанавливает прежний analytic source.

Для термальной матери \(f_1=1/(1+e^{E_1})\), постоянной rest-width Γ и изотропного двухчастичного decay получаем **точный vacuum дифференциальный источник**

\[
\boxed{
\frac{dR_\phi}{dq}=
\frac{g_1\Gamma M^2}{4\pi^2p^*}\frac{q}{E_\phi}
\left[
\ln(1+e^{-E_{1,\min}})
-\ln(1+e^{-E_{1,\max}})
\right].
}
\]

Для малого q и ненулевой mφ разность логарифмов вычисляется устойчиво через expm1 от **точного интервала** \(E_{1,\max}-E_{1,\min}=2Mqp^*/m_\phi^2\). Это предотвращает ложное зануление физического IR сигнала от потери значащих цифр.

## 2. Теорема о конечной нулевой Bose occupation SOURCE

При **любом mφ>0**, несмотря на \(dR_\phi/dq\to0\) как \(q^2\), производная occupation в нуле **не обязана** равняться нулю:

\[
\boxed{
\lim_{q\to0}\left.\frac{\partial f_\phi(q)}{\partial t}\right|_{\rm vacuum}
=
\frac{g_1}{g_\phi}\Gamma
\left(\frac{M}{m_\phi}\right)^3
\frac{1}{1+\exp(ME_\phi^*/m_\phi)}.
}
\]

Здесь правая часть — **первоначальный источник occupation** (размерность 1/время), **НЕ** плотность конденсата \(n_0\). Масса mφ→0 создаёт неравномерный по q предел: строго безмассовый формализм при конечном M/T имеет нулевой изначальный occupation-source при q=0, тогда как при малом **положительном** mφ на некотором диапазоне параметров значение может быть огромным.

Для M/T=.1, g1=4, gφ=1, Γ=1, mχ=0:

| mφ/M | Точная начальная dfφ(0)/dt / Γ |
|---:|---:|
| 0 (строго безмассовая) | 0 |
| 0.001 | ~7.71×10⁻¹³ |
| 0.005 | ~1.45×10³ |
| 0.010 | ~2.68×10⁴ |
| 0.020 | ~3.79×10⁴ |
| 0.050 | ~8.59×10³ |
| 0.100 | ~1.51×10³ |
| 0.200 | ~2.18×10² |

**Не следует считать огромную производную occupation доказательством огромного числа тёмной материи:** интегральная фазовая мера \(q^2dq\) подавляет объём самых мягких мод. У большого f(q≈0) и у измеримого холодного реликта разные физические условия. Уменьшение mφ/M ниже 0.001 при этих M/T делает нужную тепловую мать экспоненциально редкой — изначальный источник снова исчезает.

## 3. Два независимых закона полного number/energy source

Для открытого двухчастичного канала с **фиксированной собственной Γ** полная скорость рождения одной дочери не зависит от распределения массы между дочерьми:

\[
R_\phi=\frac{g_1\Gamma M}{2\pi^2}\int_0^\infty dp_1\,
\frac{p_1^2}{\sqrt{p_1^2+M^2}}\,
f_F(\sqrt{p_1^2+M^2}).
\]

При M/T=.1,g1=4,Γ=1 это **0.0164959084596**, для всех рассматриваемых mφ, пока канал открыт. Причина: лабораторное замедление decay rate ΓM/E1, а число daughter pairs равно числу decay events. Это не утверждение о постоянной скорости при фиксированном лагранжиане: **если фиксировать матричный элемент, собственная Γ меняется с фазовым объёмом и обнуляется у порога**. Чётко отделять эти две модели.

Физическая энергия распределяется в среднем изотропным двухчастичным распадом строго в долях \(E_\phi^*/M\), \(E_\chi^*/M\) от полной энергии убывающей матери. При mχ=0 доля φ равна \((1+r^2)/2\); r=.2 даёт 52% φ, 48% χ2, вместо 50/50. Полная энергия убыли матери по-прежнему \(\Gamma M n_{\chi_1}^{\rm thermal}\), равная 0.0364681857069 при выбранных единицах.

Эти формулы независимо проверены прямой Gauss/QUAD-интеграцией спектра для восьми mφ/M и самостоятельной интеграцией термального parent rate, а также прямыми \(\int_{E_{\min}}^{E_{\max}} f_F(E_1)dE_1\). На одной общей модели проверяются число, энергия, массовый порог и предел q→0.

## 4. Критический следующий физический этап

Ссылка на независимый BEST: [BEST](https://github.com/best-hep/best) v1.3.5 действительно различает massive boson и **массовую нулевую/condensate моду**. В пользовательской документации BEST прямо указано, что massless boson не имеет такой zero mode: значит модели с строго mφ=0 нельзя использовать для физической проверки BEC 86-эВ бозона.

Требуется начать с **действительно massive φ в отдельном независимом BEST 1→2 benchmark**, воспроизвести точный аналитический \(dR_\phi/dq\) и above q0 occupancy source, затем динамически эволюционировать finite-mass φ/χ2/χ1 с положительной quantum Bose/Pauli кинетикой, full FRW work/SM bath и конденсатом. Близость интегрального числа при mφ=0 **не** доказывает точность deep-IR occupation и BEC.
