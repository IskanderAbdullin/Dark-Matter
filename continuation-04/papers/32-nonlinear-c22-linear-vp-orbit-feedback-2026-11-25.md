# 32. Evolving nonlinear C22 with controlled linearized Vlasov-Poisson feedback
2026-11-25 UTC. Finite-gap lowered linear halo δ=.1. Frozen reference coordinates; evolving nonlinear collision operator, but gravity source acts on f0 only. Not fully nonlinear self-gravitating evolution.

Shell mass is obtained from the exact phase-cell overlaps W, summing angular hats. Use δQ(r_edge)=cumulative shell perturbation/Ic relative to the discrete initial state (well-balanced initial force; no artificial initial relaxation from quadrature mass error). Interpolate δQ within each shell linearly in r³, corresponding to piecewise constant density and a regular central force. Linearized gravitational source is -F'(s) sqrt(2)p δQ/r²/TIME on occupied s>0 orbits; integrate over each exact phase-shell intersection, use odd reversal to enforce per-orbit number and reference energy invariants. No δ-force acting on δf, no changing reference orbit geometry. Solve evolving nonlinear C22 plus this linear source in split stream/SSPRK2. Raw collision operator used in comparisons; aggregate radial momentum correction optional but not applied in listed runs. The independent quadratic field-energy term is -Ic/2 integral δQ²/r² dr (including outer 1/r continuation), not included in first-order energy ledger.
