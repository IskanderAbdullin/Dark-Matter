# COSMOLOGY: проверенный линейный эффект остаточной горячей компоненты
**Дата:** 2026-11-21. CLASS 3.4.3.0. [Успешный Actions run 44892770728](https://github.com/IskanderAbdullin/Dark-Matter/actions/runs/44892770728), 10 сценариев, PDF/данные не требуют доверия к приближённому баллистическому free-streaming.

## Исходная гипотеза и определения
На уровне **однотипных физически одинаковых 86-эВ бозонов**, но с двумя выделенными начальными популяциями, ввели искусственную положительную фазовую функцию
\[
f_{\alpha,w}(p)=(1-w)\,\alpha^{-3}f_{\rm BE}(p/(\alpha T_b))
+w\,f_{\rm BE}(p/T_b).
\]
Здесь \(w\) — доля ЧИСЛА частиц в первоначальном горячем хвосте, а не поздняя доля галактического неконденсата; \(\alpha\) характеризует более холодный пик. Обе формы искусственные: реальная микрокинетика Yin (2023) не тождественна этой формуле.

При любом \((\alpha,w)\) число частиц, \(m=86\) эВ и современная \(\omega_{\rm DM}\simeq0.11913\) сохраняются, а раннее
\[
\Delta N_{\rm eff}=[(1-w)\alpha+w]\,(0.064815).
\]
Малое \(w\) не гарантирует пренебрежимо малый эффект: при \(\alpha=.02,w=.05\) горячие 5% **по числу** несут ~72.5% экзотической ранней релятивистской энергии, а не 72.5% современной массы.

Для численной стабильности этот же *бесстолкновительный линейный* суммарный \(f(p)\) представлен двумя CLASS NCDM «трассерами» с одинаковой массой 86 эВ и разными температурами, к которым приложены веса \((1-w)\alpha^{-3}\) и \(w\). Это ДВЕ численные популяции **ОДНОГО физического вида частиц**, не гипотеза о двух фундаментальных видах тёмной материи. Эквивалентность справедлива только для линейного бесстолкновительного уравнения; ни рассеяния, ни превращений между потоками здесь нет.

## Десять реально рассчитанных спектров при z=5

Определяем **полумоду мощности** по \(P_{\rm Bose}(k)/P_{\rm CDM}(k)=1/2\), а не по половине амплитуды; единицы \(k\) — \({\rm Mpc}^{-1}\). Эквивалентная геометрическая диагностическая масса \(M_{\rm half}=(4π/3)\rho_{m0}(\pi/k_{\rm half})^3\) — не минимальная масса гало и не реальное ограничение из наблюдений.

| .02 | 0 | 8.76325 | 0.37290 | 7.579×10⁹ |
| .02 | .01 | 8.42785 | 0.34676 | 8.520×10⁹ |

| .01 | 0 | 16.70314 | 0.85497 | 1.095×10⁹ |

**Новый условный научный результат:** даже очень холодное начальное распределение резко теряет мощность на малых масштабах при появлении умеренной горячей популяции. При \(\alpha=.01\) рост \(w\) с 0 до 20% увеличивает геометрический \(M_{\rm half,P}\) примерно в **585 раз**; при \(\alpha=.02\) — примерно в **171 раз**. Это *не* наблюдательные границы на w, потому что ни один выбранный \(\alpha,w\) не выведен из микрофизики и не сопоставлен с данными.

## Численная сходимость и ограничения
Все 10 CLASS прогонов успешны. Для 6 отдельных репрезентативных точек \(w\in\{0,.05,.2\}\) в каждой группе \(\alpha\) проведены независимые тонкая/грубая сетки каждого компонента (около 7700 и 4100 точек). Максимальная относительная ошибка мощности до первого \(k_{\rm half,P}\) между двумя сетками:
- \(\alpha=.02:\) 0.00139%, 0.00175%, 0.00277% для \(w=0,.05,.2\);
- \(\alpha=.01:\) 0.00174%, 0.00192%, 0.00368% для \(w=0,.05,.2\).

Относительный сдвиг самого \(k_{\rm half,P}\) **не больше ~0.0022%** в этих шести сравнениях. Остальные четыре сценария подтверждены единственной тонкой сеткой и сравнением аналитических интегралов числа/энергии, но не прямой независимой сеточной проверкой — отличать их точность необходимо. При сильном подавлении далеко за порогом спектр остаётся чувствительным к численным параметрам Boltzmann-решателя, и периодические высокочастотные особенности нельзя считать установленной физикой.

Искусственный cold+hot PSD **не выведен** из микрофизического процесса \(\chi_1\leftrightarrow\chi_2+\phi\). Вместе с [действительно рассчитанной квантовой кинетикой](../kinetics/VERIFIED-QUANTUM-BURST.md) он задаёт строгую программу: сначала сходимость конкретного рождения \(f_\phi(q)\), затем CLASS с ЭТИМ \(f_\phi(q)\), затем проверка late galaxy formation and BE thermalization. До этого никаких универсальных массовых или процентных ограничений на «горячую долю» нет.
