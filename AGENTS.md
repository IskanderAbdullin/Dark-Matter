# AGENTS — карта проекта Dark-Matter

**Область:** весь публичный репозиторий; научная цель определена в [GOAL.md](GOAL.md). [PROJECT_MAP.md](PROJECT_MAP.md) — карта разделов; [PLAN.md](PLAN.md) — короткая карта живого плана. **Не читать всё перед любой правкой:** выбирай релевантные источники по задаче.

- **Кинетика:** [специальное ТЗ](kinetics/CONTINUOUS-RESEARCH-SPEC.md), [GOAL](kinetics/research-control/GOAL.md), [STATE](kinetics/research-control/STATE.json) → [NEXT_ACTION](kinetics/research-control/NEXT_ACTION.json); при физическом расчёте и интерпретации [обязательные научные инварианты](kinetics/RESEARCH_GUARDRAILS.md).
- **Гало/галактические профили:** по [PROJECT_MAP](PROJECT_MAP.md) выбрать code, продолжения исследований и результаты; не предполагать доказанную связь с кинетикой без проверки.
- **Архив:** [archive/README.md](archive/README.md) → [CHRONOLOGY](archive/CHRONOLOGY.md). Сохранять в **публичном Git** значимые гипотезы, исходники/результаты, отрицательные тесты, provenance, графики и воспроизводимые протоколы; временные GitHub Actions artifacts не считаются архивом.
- **Цикл:** самостоятельно выбрать проверяемый вопрос → применить релевантный научный метод/проверки → записать доказательства и ограничения → commit/push без force → обновить фактический checkpoint и следующий шаг → продолжить в пределах сеанса. План и метод можно менять по доказательствам, цель — только по решению пользователя.
- **Научная честность:** физическая согласованность ≠ зелёный CI; synthetic ≠ независимая верификация; BEC, relic Ω, CLASS-ready и завершение всей программы **не предполагать** без соответствующих ворот в ТЗ и [RESEARCH_GUARDRAILS](kinetics/RESEARCH_GUARDRAILS.md). Все утверждения ссылать на первоисточники/проверяемые результаты.
- **Безопасность:** никаких секретов, аккаунтов, приватных данных, нарушения лицензий, force-push, автоматического merge непроверенных результатов и управления ПК/Computer Use без явного разрешения. Публичный CI применять разумно, без тяжёлых ненужных матриц.

Подробные процедуры, фиксированные значения/единицы и ограничения находится в профильных документах; эта карта не заменяет их. Не объявлять работу фоновой без действительного планировщика.


## Правило остановки при блокировке исследовательского запуска

**Частная блокировка не является условием завершения.** Если расчёт, инструмент, CI, сеть, файл, внешний API, эксперимент или физическая гипотеза не допускает дальнейшего шага, агент:

1. Фиксирует конкретный блокер (операция, точная ошибка/отрицательное доказательство, SHA, дата UTC, зависимость, что уже проверено), **не** выдумывает время ожидания и **не** повторяет бессмысленно одну и ту же проверку.
2. Пробует разумную альтернативу в рамках имеющихся полномочий: другой метод, независимый физический вопрос, теоретический вывод, тест/доказательство с меньшими ресурсами, отдельная работа по гало/наблюдениям или задача из BACKLOG. При этом не обходит научные критерии и не смешивает несравнимые модели.
3. Если затронуто редактирование общей ветки/конфликт, не применяет force или merge: работает с безопасным независимым этапом, а конфликт документирует.
4. **Досрочно останавливается по причине blocked лишь тогда, когда все существенно полезные разрешённые направления объективно недоступны в текущей среде или исчерпаны её технические возможности.** Не считать блокировкой недостаточность доказательств, один красный CI, отсутствие окончательного физического ответа, очередь CI или завершённый коммит. Не запускать искусственную работу ради длительности.
5. Перед досрочной остановкой записывает в STATE.json фактический stop_reason, UTC начала/окончания и длительность **реальной** работы, доказательства/отрицательные результаты; в NEXT_ACTION.json — **один конкретный разблокирующий шаг** с необходимой зависимостью и безопасную независимую альтернативу. Сохраняет Git-коммит без force, если Git доступен; иначе сообщает, что именно не сохранено и почему.

**Обычное завершение:** физическая конечная цель доказательно достигнута, либо истёк фактический лимит активного запуска с завершением ближайшего безопасного этапа. Если среда принудительно завершает запуск раньше — фиксировать фактически выполненный объём, а не обещать продолжение в фоне. Это правило действует на оба направления общей цели, не подменяет её и не даёт новых разрешений на Computer Use.
