- **Требование:** публичная долговременная хронология исследований, не зависимая от срока хранения GitHub Actions

## Исследовательский вопрос и метод

Проверить, какой объём текущей публичной работы уже сохранён в истории Git, и превратить разрозненные журналы в единый индекс с постоянными ссылками. Использованы только фактически достижимые по ветке Git commits и рекурсивный Git tree; история упорядочена по committer UTC, а не предполагаемому началу физического эксперимента.

## Действительно сохранено

- 233 существующих Git-коммита за 2026-11-21 и 2026-11-22; каждый содержит полный SHA, дату committer UTC, тему и **полный текст commit message** в JSONL.
- Для быстрого чтения созданы две Markdown-таблицы с UTC, ссылкой на конкретный commit diff и темой.
- 555 версионированных файлов исходного дерева; сохранены имена, Git blob SHA и размер, а также ссылочный каталог машинных результатов.
- Главный [научный указатель](../../../MILESTONES.md) связывает события с оригинальными численными JSON, отчётами и известными ограничениями.

## Воспроизведение

Указать commit/branch и выполнить `git log --format=fuller` либо GitHub REST `GET /repos/IskanderAbdullin/Dark-Matter/commits?sha=<SHA>&per_page=100&page=N` и `GET /repos/IskanderAbdullin/Dark-Matter/git/trees/<SHA>?recursive=1`. Сопоставить записи с [chronology](../../../chronology/2026-11-21.md) и [catalog snapshot](../../../catalog/snapshot-2026-11-22.json). Реальное восстановление больших внешних исходных данных и независимая репликация всех расчётов в этом этапе **не выполнялись**.

## Ограничения, отрицательные результаты и неполнота

Архивная реконструкция фиксирует **все достижимые коммиты**, но не способна восстановить то, что **не было коммичено**. Нельзя утверждать наличие старых истёкших Actions artifacts, временных лабораторных выходов, неизданных файлов или закрытых исходных данных. Некоторые ссылки Actions в прежних отчётах со временем могут перестать работать; ключевую научную информацию необходимо сохранить в самом Git.

По возможности ретроспективно переносить из временных внешних источников научно значимые данные с проверкой лицензий и конфиденциальности, **не копировать гигабайты механически**.
